# Memelang CS 101–103 Stress Corpus & 2-Axis Gap Harness — Design Spec

**Date:** 2026-11-03  
**Project:** `memelang` (`tests/corpus/`, `scripts/run_corpus.py`)  
**Status:** Draft for Review

---

## 1. Overview & Architectural Alignment

Memelang (`meme`) is extendable along **two distinct axes** (the two this corpus measures — the compiler's third extension axis, its own LLM frontend, is documented in `2026-11-03-memelang-design.md` §9):
1. **`examples/` Axis (Syntax & Library Extensibility):** Pre-installed and user-authored `.meme` files in `examples/` serve as Memelang's live syntax/idiom bank ("Memelang is as smart as you make it"). `examples/` must remain curated and free of test clutter.
2. **`src/` Language Axis (IR & Output Target Extensibility):** The typed Intermediate Representation (`src/memelang/ir/`), static verifier (`src/memelang/analyzer/`), and code generators (`src/memelang/codegen/`) determine structural operations and target output languages (`python`, `rust`, `cpp`, and future backends).

This spec defines an **unfiltered 300-script university Computer Science (CS 101–103) test corpus** living strictly under `tests/corpus/`, written in the project author's natural Memelang voice, paired with sample input fixtures, a structured `manifest.json`, and a standalone evaluation & gap-attribution runner (`scripts/run_corpus.py`).

### Goals
- Provide **300 genuinely distinct university CS homework/lab programs** (`100` CS 101, `100` CS 102, `100` CS 103) — no numeric clones or trivial constant swaps.
- Faithfully mirror how the author writes `.meme` programs in practice, including an **80% clean / 10% typo-resilience / 10% semantic-ambiguity** distribution per course.
- Express CS 101–103 algorithms naturally — even when a script uses idioms or data structures not yet supported by the compiler — so running the corpus measures real-world readiness and attributes failures cleanly to the **`examples` axis** vs the **`language` axis**.
- Keep `uv run pytest` fast (`<20s`) by validating corpus integrity and runner classification via unit tests (`tests/test_corpus_manifest.py`) while running live LLM batch evaluations on demand via `scripts/run_corpus.py`.

## 3. Authorial Voice & Style Distribution

Every `.meme` script is authored in the user's established Memelang style observed across `examples/hello.meme`, `examples/calc.meme`, and both revisions of `examples/find-largest.meme`:

### Core Idioms Used Across the Corpus
1. **Shell Header:** Interactive and CLI scripts open with `this runs in the shell`.
2. **Program Structure:**
   - **Flat Shell Scripts (common in early CS 101):** Top-level `define <var> as input from user "<Prompt>?"` / `define <var> from user "<Prompt>?"`, arithmetic/conditionals/loops, and `print <expr>` / `print result of ...`.
   - **Class-Scoped Multi-Function Programs (late CS 101, CS 102, CS 103):**
     ```meme
     this runs in the shell

     class binary-search

       define function loadFile with filepath
         if filepath is json
           define list as fromFile from filepath
           return fromFile
         else return "Wrong File Type"

       define function searchList with list, target
         for i from 1 to length of list
           if list item i == target
             return i
         return -1

       define function main
         define filepath from user "Filepath?"
         define target from user "Target?"
         define pos as searchList from loadFile filepath, target
         print pos
     ```
3. **Hybrid Declarative + Procedural Phrasing:**
   - High-level declarative English (`sort unsorted into sorted ascending`, `return largest from sorted`, `filter scores where score >= 60`).
   - Step-by-step procedural English (`check list item 1 against list item 2`, `foreach item x in list starting at item 2`, `move each item in stack up 1`, `set dp item i to ...`).
   - 1-based human positions (`item 1`, `item 2`, `item last`) alongside natural loop variables (`for i from 1 to n`, `while low <= high`).

### Per-Course Style Quotas (Exact Counts)
Within **each** 100-script course (`cs101`, `cs102`, `cs103`), scripts follow an exact **80 / 10 / 10** split (`240 / 30 / 30` total):
- **`clean` (80 per course / 240 total):** Natural, unambiguous Memelang as normally written.
- **`typo` (10 per course / 30 total):** Realistic human keyboard/prose slips that a resilient frontend should heal without halting:
  - Prompt/keyword typos (`from use "Number?"`, `retrun total`, `pirnt answer`, `deifne count as 0`).
  - Identifier/alias slips (`sorterd`, `findLagest`, `lenght`, `define list as fromFile from filepath` followed by `return fromFile`).
- **`ambiguous` (10 per course / 30 total):** Genuinely contradictory or underspecified English expected to trigger Memelang's ambiguity diagnostic (`exit code 2`, `--resolve`):
  - Loop-mutation collisions (`foreach item in nums` mutating/sorting/filtering `nums` inside the loop).
  - Lossy partial-insertion / one-branch updates contradicting function name or postcondition (`findLargest` / `fullSort` skipping `else` elements).
  - Underspecified bounds or tie-break contradictions (`generate 10 random numbers` + `clamp/sort from 1 to 10` inside loop; `between 1 and 10` exclusive vs inclusive contradictions; "sort from smallest to largest descending").

## 5. Manifest Schema (`tests/corpus/manifest.json`)

`manifest.json` contains a top-level metadata header and a `scripts` list of 300 entries:

```json
{
  "corpus_version": 1,
  "total_scripts": 300,
  "scripts": [
    {
      "id": 1,
      "slug": "001_hello_banner",
      "path": "tests/corpus/cs101/001_hello_banner.meme",
      "course": "cs101",
      "topic": "io_and_math",
      "title": "Course Welcome Banner",
      "style": "clean",
      "stdin": "Ada\n",
      "expected_status": "ok",
      "expected_stdout_contains": "Ada",
      "feature_tags": ["read_input", "string_concat", "print"],
      "extensibility_gaps": {
        "examples": [],
        "language": []
      }
    }
  ]
}
```

### Field Definitions
- **`id`**: Integer `1..300`.
- **`path`**: Repo-relative POSIX path under `tests/corpus/{cs101,cs102,cs103}/`.
- **`course`**: `"cs101" | "cs102" | "cs103"`.
- **`topic`**: Curriculum sub-cluster slug.
- **`style`**: `"clean" | "typo" | "ambiguous"`.
- **`stdin`**: Deterministic newline-terminated input string fed to `meme run` (empty `""` if non-interactive).
- **`expected_status`**: `"ok"` (for `clean` and `typo` scripts) or `"ambiguous"` (for `ambiguous` scripts expected to halt with `AmbiguityDiagnostic`).
- **`expected_stdout_contains`**: Non-empty substring/scalar expected on stdout when `expected_status == "ok"`, or `""` when `expected_status == "ambiguous"`.
- **`feature_tags`**: Required language/algorithmic capabilities.
- **`extensibility_gaps`**:
  - **`examples`**: List of syntax/idiom patterns not yet demonstrated in `examples/` (e.g., `"english_swap_phrase"`, `"preposition_multi_arg_call"`, `"1_based_slice_phrase"`).
  - **`language`**: List of IR/verifier/codegen capabilities not yet in `src/memelang/` (e.g., `"list_set_index"`, `"string_indexing"`, `"string_len"`, `"dict_map"`, `"nested_2d_list"`, `"json_string_list"`).

## 6. Corpus Runner & 2-Axis Gap Reporter (`scripts/run_corpus.py`)

`scripts/run_corpus.py` is a zero-extra-dependency Python CLI tool that imports `memelang` directly (in-process so the GGUF model loads once in VRAM across the entire run rather than reloading 300 times!).

### CLI Flags
- `--course {all,cs101,cs102,cs103}` (default: `all`)
- `--style {all,clean,typo,ambiguous}` (default: `all`)
- `--ids 1-20,105,210` (optional ID range/list filter)
- `--limit N` (optional cap for quick smoke runs)
- `--provider <spec>` (default: `auto`)
- `--target {python,rust,cpp}` (default: `python`)
- `--timeout <sec>` (default: `10.0` per script execution)
- `--report <path.json>` (optional machine-readable JSON report output)

### Outcome Buckets & 2-Axis Attribution
For each script (using a temporary lockfile so `build.lock` in the repo root is never touched):
1. **`PASS`**: Compiled, executed with `returncode == 0`, and matched `expected_stdout_contains`.
2. **`AMBIGUOUS_EXPECTED`**: `expected_status == "ambiguous"` and compiler halted with `AmbiguityDiagnostic`.
3. **`AMBIGUOUS_UNEXPECTED`**: `expected_status == "ok"` but compiler emitted an unexpected ambiguity.
4. **`MISSED_AMBIGUITY`**: `expected_status == "ambiguous"` but compiler silently compiled without warning.
5. **`SYNTHESIS_ERROR`**: LLM frontend failed schema/JSON synthesis.
6. **`STATIC_VERIFY_GAP`**: Synthesized IR failed static verification (undeclared symbol, unsupported mutation, type mismatch).
7. **`CODEGEN_OR_RUNTIME_ERROR`**: Target compilation or execution exited non-zero / timed out.
8. **`OUTPUT_MISMATCH`**: Program exited `0` but stdout did not match `expected_stdout_contains`.

At completion, `run_corpus.py` prints:
- Per-course (`cs101`, `cs102`, `cs103`) and per-style (`clean`, `typo`, `ambiguous`) pass rates.
- **Axis 1 (`examples/` Syntax & Library Extensibility) Top Gaps:** Ranked counts of `extensibility_gaps.examples` across non-passing scripts (showing which new `.meme` reference files in `examples/` will unlock the most scripts).
- **Axis 2 (`src/` IR & Output Language Extensibility) Top Gaps:** Ranked counts of `extensibility_gaps.language` across non-passing scripts (showing which IR nodes / backend codegen additions unlock the most scripts).

## 7. Automated Verification (`tests/test_corpus_manifest.py`)

Fast (`<1s`) unit tests run automatically in `uv run pytest`:
1. Verify `tests/corpus/manifest.json` parses cleanly and contains **300** entries (`1..300`).
2. Verify exact course split (`100` `cs101`, `100` `cs102`, `100` `cs103`) and exact style split (`80` `clean`, `10` `typo`, `10` `ambiguous` per course).
3. Verify every referenced `.meme` file and every `tests/corpus/fixtures/*` file exists on disk, is non-empty, has unique normalized content (zero duplicate scripts!), and keeps `examples/` free of test corpus files.
4. Verify `scripts/run_corpus.py` outcome classification and 2-axis gap aggregation using a fast deterministic mock/heuristic slice (`--limit 5 --provider heuristic`).
